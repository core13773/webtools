Base64 인코더 / 디코더

텍스트 ↔ Base64 간 변환을 손쉽게 수행하세요. UTF-8을 기준으로 처리됩니다.

결과가 여기에 표시됩니다.
📢 컨텐츠 내 광고 영역

📖 사용 방법

1
텍스트 입력

인코딩하거나 디코딩할 텍스트를 입력창에 입력합니다. 한글, 특수문자 등 모든 UTF-8 문자를 지원합니다.

2
인코딩 또는 디코딩

입력한 텍스트를 Base64로 변환하려면 🔼 인코딩 버튼을, Base64를 원래 텍스트로 복원하려면 🔽 디코딩 버튼을 클릭합니다.

3
결과 활용

📋 결과 복사 버튼으로 변환된 값을 클립보드에 저장하거나, 🗑️ 초기화 버튼으로 입력을 지웁니다.

💡 팁: Base64는 이메일 첨부파일, 데이터 URI, API 인증 토큰 등 다양한 곳에서 사용됩니다. 디코딩 시 올바른 Base64 형식인지 확인하세요.
