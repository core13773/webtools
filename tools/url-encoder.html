📢 컨텐츠 내 광고 영역

📖 사용 방법

1
URL 또는 텍스트 입력

인코딩할 URL이나 텍스트를 입력합니다. 예: https://example.com/검색?q=안녕

2
인코딩 또는 디코딩

🔼 인코딩 버튼으로 한글, 공백, 특수문자를 %EB%AC%B8%EC%9E%90 형식으로 변환합니다. 🔽 디코딩 버튼으로 다시 원래 문자로 복원할 수 있습니다.

3
결과 확인 및 복사

변환된 URL을 확인하고 📋 결과 복사 버튼으로 클립보드에 저장합니다. 잘못된 인코딩 문자열은 디코딩 시 오류가 표시됩니다.

💡 팁: URL 인코딩은 웹 브라우저가 URL을 안전하게 전송하기 위해 필요합니다. 쿼리 파라미터에 한글이나 특수문자가 포함된 경우 필수로 사용됩니다.
