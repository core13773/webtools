JSON 포맷터 & 유효성 검사

JSON 문자열을 보기 좋게 정렬하고 문법 오류를 확인하세요.

결과가 여기에 표시됩니다.

📖 사용 방법

1
JSON 입력

정렬이 필요한 JSON 문자열을 입력창에 붙여넣습니다. 예: {"name":"WebTools","version":1}

2
옵션 선택

키 알파벳 순 정렬 체크 시 객체 키가 가나다순으로 정렬됩니다. 간결하게 (2칸 들여쓰기) 로 들여쓰기 간격을 조절할 수 있습니다.

3
포맷팅 또는 최소화

✨ 포맷팅 버튼으로 JSON을 보기 좋게 정렬하거나, 🗜️ 최소화 버튼으로 공백을 제거하여 용량을 줄입니다.

4
결과 복사

📋 결과 복사 버튼으로 변환된 JSON을 클립보드에 저장합니다. JSON 문법이 잘못된 경우 오류 메시지가 표시됩니다.

💡 팁: JSON 데이터는 브라우저 내에서만 처리되며 서버로 전송되지 않습니다. 민감한 데이터도 안전하게 사용하세요.
