텍스트 케이스 변환

텍스트를 다양한 형식(대문자, 소문자, camelCase 등)으로 변환합니다.

결과가 여기에 표시됩니다.

📖 사용 방법

1
텍스트 입력

변환할 텍스트를 입력합니다. 예: hello world 또는 my_variable_name

2
변환 방식 선택

원하는 형식의 버튼을 클릭합니다: 대문자 (HELLO) · 소문자 (hello) · Capital Case (Hello World) · snake_case (hello_world) · camelCase (helloWorld)

3
결과 복사

변환된 텍스트를 확인하고 📋 복사 버튼으로 클립보드에 저장합니다. 필요시 🗑️ 초기화 버튼으로 입력을 지웁니다.

💡 팁: snake_case 는 Python 변수명, camelCase 는 JavaScript 변수명에 주로 사용됩니다. Capital Case는 제목이나 이름을 작성할 때 유용합니다.
