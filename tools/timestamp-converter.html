📖 사용 방법

1
현재 시간 확인

상단에 현재 Unix 타임스탬프(초)와 날짜/시간이 1초 간격으로 자동 갱신되어 표시됩니다.

2
타임스탬프 입력 및 변환

변환할 Unix 타임스탬프(초 또는 밀리초 단위)를 입력하고 🔄 변환 버튼을 클릭합니다. 초 단위(10자리)와 밀리초 단위(13자리)를 자동으로 구분합니다.

3
현재 시간으로 변환

⏰ 현재 시간 사용 버튼으로 현재 시각의 타임스탬프를 즉시 변환할 수 있습니다. 변환 결과는 📋 복사 버튼으로 저장하세요.

💡 팁: Unix 타임스탬프는 1970년 1월 1일(UTC)부터 경과된 초(또는 밀리초)입니다. API 응답, 로그 파일, 데이터베이스에서 날짜 처리 시 자주 사용됩니다.
