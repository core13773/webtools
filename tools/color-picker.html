Color Converter

Convert between HEX, RGB, and HSL color codes with live preview.

📖 How to Use

1
Select a Color

Use the color picker or enter a HEX code directly (e.g. #4f46e5).

2
View Converted Values

RGB and HSL values are automatically calculated and displayed.

3
Copy or Randomize

Click on any field to copy its value. Click 🎲 Random Color to generate a random color.

💡 Tip: HEX is the most common color format in web design, while RGB and HSL are frequently used in CSS for dynamic color manipulation.
