색상 변환기

HEX, RGB, HSL 색상 코드를 자유롭게 변환하고 색상을 미리보세요.

📢 컨텐츠 내 광고 영역

📖 사용 방법

1
색상 선택

컬러 피커( 🖌️ )를 클릭하여 원하는 색상을 직접 선택하거나, HEX 코드(예: #4f46e5 )를 직접 입력합니다.

2
변환 결과 확인

RGB( rgb(79, 70, 229) )와 HSL( hsl(244, 74%, 59%) ) 값이 자동으로 변환되어 표시됩니다.

3
값 복사 및 랜덤 생성

각 입력 필드를 클릭하면 해당 값이 클립보드에 복사됩니다. 🎲 랜덤 색상 버튼으로 무작위 색상을 생성할 수 있습니다.

💡 팁: 웹 디자인에서 색상 코드는 HEX가 가장 흔하게 사용되며, CSS에서는 RGB와 HSL도 자주 활용됩니다. 미리보기를 통해 실제 색상을 확인하세요.
