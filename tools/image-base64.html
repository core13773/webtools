이미지 Base64 변환

이미지 파일을 드래그앤드롭 또는 파일 선택으로 Base64 문자열로 인코딩합니다.

📤

이미지를 여기에 드래그하거나 클릭하여 선택하세요

📖 사용 방법

1
이미지 업로드

파일을 드래그앤드롭하거나 클릭하여 이미지 파일(JPG, PNG, GIF, SVG 등)을 선택합니다.

2
자동 인코딩

이미지가 선택되면 즉시 Base64 문자열로 변환되어 표시됩니다.

3
복사 또는 다운로드

📋 복사 버튼으로 Base64 문자열을 클립보드에 저장하거나, 💾 다운로드로 텍스트 파일로 저장합니다.

💡 팁: Base64 인코딩된 이미지는 CSS background-image나 HTML img 태그의 src 속성에 직접 사용할 수 있습니다. 다만 파일 크기가 약 33% 증가하니 큰 이미지는 주의하세요.
