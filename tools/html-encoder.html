HTML 인코더 / 디코더

특수문자를 HTML Entity(&lt;, &amp; 등)로 변환하거나 되돌립니다.

결과가 여기에 표시됩니다.

📖 사용 방법

1
텍스트 입력

HTML 특수문자가 포함된 텍스트를 입력합니다. 예: <div>안녕하세요! &quot;WebTools&quot;</div>

2
인코딩 또는 디코딩

🔼 HTML 인코딩 버튼으로 < , > , & 등을 HTML Entity로 변환합니다. 🔽 HTML 디코딩 버튼으로 다시 원래 문자로 복원합니다.

3
결과 복사

📋 결과 복사 버튼으로 변환된 HTML을 클립보드에 저장합니다. 인코딩된 HTML은 웹페이지에 안전하게 삽입할 수 있습니다.

💡 팁: HTML 인코딩은 XSS(크로스사이트 스크립팅) 공격을 방지하고, 사용자 입력을 안전하게 웹페이지에 표시할 때 필수적으로 사용됩니다.
