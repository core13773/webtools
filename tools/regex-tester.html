Test regex patterns in real time with match highlighting and replacement.

📖 How to Use

1
Enter Pattern

Type the regex pattern to test. e.g. \d+, [a-z]+

2
Enter Test String

Type the string to apply the pattern to. Matches are highlighted in real time.

3
Replace (Optional)

Enter a replacement string and click 🔄 Replace to see the substituted result.

💡 Tip: g flag = global search, i = case-insensitive, m = multiline mode.
