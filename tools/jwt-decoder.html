JWT 디코더

JWT(JSON Web Token)의 헤더, 페이로드, 서명을 디코딩하고 claims를 확인합니다.

📖 사용 방법

1
JWT 입력

디코딩할 JWT 토큰을 입력합니다. 예: eyJhbGciOiJIUzI1NiIs...

2
디코딩 확인

🔓 디코딩 버튼을 클릭하면 헤더, 페이로드, 서명이 분리되어 표시됩니다.

3
결과 복사

📋 복사 버튼으로 헤더나 페이로드를 클립보드에 저장합니다.

💡 팁: JWT는 서버 인증에 많이 사용됩니다. 페이로드는 Base64Url로 인코딩되어 있어 누구나 읽을 수 있으나, 서명을 통해서만 위변조 여부를 확인할 수 있습니다.
