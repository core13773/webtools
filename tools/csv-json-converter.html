CSV ↔ JSON 변환기

CSV 데이터를 JSON 배열로, JSON을 CSV로 자유롭게 변환합니다.

결과가 여기에 표시됩니다.

📖 사용 방법

1
데이터 입력

CSV 또는 JSON 데이터를 입력합니다.

2
변환 방향 선택

CSV → JSON 또는 JSON → CSV 버튼을 클릭합니다.

3
결과 복사

변환된 결과를 확인하고 📋 복사 버튼으로 저장합니다.

💡 팁: CSV의 첫 줄을 헤더로 사용하면 JSON 객체 배열로, 사용하지 않으면 2차원 배열로 변환됩니다.
